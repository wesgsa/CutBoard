# 자재 자르기 프로그램

## 프로그램 설명
이 프로그램은 자재 자르는 방법을 알려줍니다. 현재 가지고 있는 원자재 판의 크기와 필요한 조각의 크기를 입력하면 어떻게 효율적으로 자를지 알려줍니다. 
이 프로그램을 사용하면 기존에 무작위로 자르는 방법에 비해서 남는 자투리 공간을 아끼고 전체 사용하는 원자재 판의 개수까지 효율적으로 사용할 수 있습니다.


## 프로그램 기능
단순히 자재를 배치하는 것을 넘어서 더 구체적이고 실용적으로 사용할 수 있도록 여러가지 기능을 제공합니다.

현재 제공하는 기능은 아래와 같습니다.

- 자르기 배치 설정
  - 회전 가능 여부
  - 원자재판 테두리 여유 간격
  - 조각 사이의 간격 설정(kerf)
  - 직선 재단 가능하도록 자르기(guillotine)

- 배치 통계 제공
  - 사용한 조각과 실패한 조각의 수
  - 자재 사용률(%)
  - 사용한 자재의 수

## 프로그램 사용방법
- 원자재 판, 자를 조각 글씨 옆에 있는 + 버튼을 눌러 판과 조각을 추가할 수 있습니다.   
- 여기서 가로, 세로, 수량을 입력할 수 있습니다. 단위는 딱히 중요하지 않습니다.   
- 모든 입력을 끝낸 후에 아래에 **최적화된 자르기 실행** 버튼을 눌러 배치를 수행합니다. 이 과정은 조각이나 판이 수정되었을 때 다시 눌러야 합니다.   
- 아래 작업 통계 칸에서 위 아래 모양 화살표를 눌러 접고 열 수 있습니다.   
- 만약 사용된 원자재 판의 개수가 여러 개일 경우 배치도 오른쪽 위에 있는 앙쪽 화살표로 여러 원자재 판을 자르는 방법을 볼 수 있습니다.
